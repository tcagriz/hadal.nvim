# Security policy

This repository is a synchronized mirror. The source of truth and canonical
security policy are in
[tcagriz/hadal-theme](https://github.com/tcagriz/hadal-theme/blob/main/SECURITY.md).

Do not open a public issue for suspected vulnerabilities or exposed
credentials. Use
[private vulnerability reporting](https://github.com/tcagriz/hadal-theme/security/advisories/new)
in the monorepo, identify the Neovim package and include the affected Neovim
and plugin version.
